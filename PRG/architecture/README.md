# BLAST ARCHITECTURE SOPs

This directory contains the Technical Standard Operating Procedures (SOPs) for the project.
According to the BLAST Protocol Phase 3 (Architect), logic must be defined here *before* code is written.

## Active SOPs
*   `sop_001_initialization.md`: Rules for project setup and stack definition.
*   `sop_002_booking_flow.md`: Logic for the Agentic Booking system.

## The Golden Rule
> **If you need to change the logic, update the SOP first, then the code.**
